# A part of Hatchling

This crate is one part of [Hatchling](https://github.com/undergroundrap/hatchling): personal AI agents you actually own, in kernel-isolated cells that never hold your keys.

It's published so the `hatchling` command can be installed:

```bash
cargo install hatchling-runtime
```

It carries no stability promise on its own: its API changes whenever Hatchling needs it to, and a 0.x minor version may break it. Depend on it directly only if you're prepared to follow Hatchling's releases.
