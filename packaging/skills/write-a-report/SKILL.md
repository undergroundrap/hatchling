# Write a report

**Purpose:** a finished run has handed the owner a report file whose every
load-bearing claim traces to a source the run actually read.

**Before you start:** this needs your computer (`write`, `give_file`). In a
run without one, say that a report needs a chat with the computer, and stop.

## Inputs

- The topic, and the question the report answers.
- The audience: the owner, or someone the owner will send it to.
- The sources in scope: which workspace folders, which Library items the
  owner handed back, and whether the web is in scope.

If the topic is ambiguous between two readings that would produce different
reports, ask once, with both readings stated.

## Steps

1. **Gather before writing.** Read the in-scope material in the workspace,
   and `search` it for the topic's terms. If the web is in scope, use
   `web_search` first, then `web_fetch` and read the strongest sources:
   search snippets are leads, not evidence. If a site isn't granted, ask
   through the usual request and go on with what you have.
2. **Make a private outline** in the workspace: the sections, and under
   each, the sources it rests on. A section with no source is cut, or marked
   as the owner's own position, as the owner directs.
3. **Draft the report** as a file in the workspace, with `write`. Plain
   structure: what was asked, what was found, what it means, what remains
   open. Keep claims at the strength of their sources.
4. **Check the draft against the sources:** every number, date, name and
   quotation re-read at its source. Fix or soften anything that doesn't
   check out.
5. **Hand the file over** with `give_file`.

## Guardrails

- Never invent a source, a figure or a quotation.
- Never present a search snippet as something read.
- If two sources disagree on a load-bearing point, the report says so, and
  which it follows and why.
- Estimates are labelled estimates.

## Stop and ask

- The in-scope material doesn't cover the topic, and the web isn't in scope.
- The only sources are ones the run can't read.
- The owner named a conclusion the sources contradict: report the
  contradiction and ask; don't write around it.

## The answer

Name the file, the sources used, and anything that could not be verified.
